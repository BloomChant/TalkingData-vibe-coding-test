# 前端说明（Claude）

前端由后端在 `http://localhost:8000/` 托管。源码就是 `web/dist`：原生 ES module，不需要构建，也没有 npm 依赖，所以 Docker 构建时不必联网安装前端依赖。

## 页面
| 页面 | 回答的问题 | 内容 |
|---|---|---|
| 总览 | 这个世界有什么、正在发生什么 | 6 个指标卡；入库节奏和平均延迟两张图，共用时间轴、各用各的 Y 轴；顶层类目构成（点击可跳到探索页过滤）；世界动态（分类的新增、改名、迁移等真实事件）；用真实统计生成的世界日志 |
| 探索 | 怎么组织和理解陌生对象 | 4 个抽象视角共用一套过滤状态（见下） |
| 可信与系统 | 数据可信吗、系统撑得住吗 | 回执对账：逐项检查，加上批次像素条；隔离区；cgroup 资源计量（内存、CPU、磁盘水位） |

## 探索页：信息抽象和视图过滤
- **4 个视角**：
  - 分类树：来自发生器原样；计数含子类。
  - 对象种类：由名称派生，界面上标"派生"。
  - 空间层级：`frame_id` 路径，星系 / 恒星系 / 世界，再加坐标类型。
  - 字段目录：对 `attributes` 做有界抽样统计，标出覆盖率、取值类型和混合类型。
- **统一过滤**：
  - 每个视角同时也是过滤器。条件以标签形式显示在顶部，可以逐个移除。
  - 同一维度内多选是"或"，不同维度之间是"且"。
  - 计数来自 `/api/facets`，每个维度计数时忽略它自身的过滤条件，所以你能看到"如果改选别的，会有多少"。
- **空间分布**：只有选中一个**具体参考系**时才画二维散点，因为不同参考系单位不同，不混在一起画。点数来自"最新接收的若干个"，不是无偏抽样。
- **对象详情**：类型路径、位置、`attributes` 原样按层级展示，并附原始 JSON。

## 数据语义边界
- 不臆造协议里没有的东西：对象没有版本；没有 family 字段；`position=null` 显示为"未提供位置"；没有对象之间的归属关系。
- 派生值（种类、顶层类目）一律标注为派生，规则见 `contracts/API.md`。

## 验证
- 接口：`node contracts/check.mjs http://localhost:8000`。在 correctness-001 和 throughput-max 上，14 个接口全部符合契约。
- 页面：用无头 Chrome 对 3 个页面截图，在 throughput-max（181,600 个对象）上人工检查过渲染。

## 已知限制
- 没有自动化的 UI 测试，只做了截图检查。
- 字段目录目前只用来展示，还不能按"有某个字段"过滤。
- facets 是精确的全量聚合，18 万对象时单次请求约 1.3 秒。前端对过滤做了防抖，计数不随速率图每秒刷新。
